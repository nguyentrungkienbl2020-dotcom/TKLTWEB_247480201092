1. CSS là gì?

Trong lĩnh vực xây dựng, chúng ta có trang trí nội thất. Trong thiết kế web, CSS giúp định dạng trang web.

2. Học CSS cần những gì?

  • Một trình soạn thảo CSS
  • Trình duyệt
  • Thời gian thực hành CSS

3. Những lệnh thường gặp trong CSS
